# USB PD Charger — 20 портов

Проект KiCad 9.0.6: GD32F470, SDRAM, дисплей 480×272, 20 зарядных USB-C портов.

Открывать **USB_PD_Charger_hw/USB_PD_Charger.kicad_pro**.
Единственная рабочая плата — **USB_PD_Charger_hw/USB_PD_Charger.kicad_pcb**.
Три файла схемы, fp-lib-table, sym-lib-table и каталоги libs входят в проект и нужны для его редактирования. libs/Symbols/ProjectCache содержит рабочие проектные библиотеки, это не временный кеш.

- `USB_PD_Charger_hw/release/FINAL_REVIEW.md` — итоговая проверка и открытые параметры заказа.
- `USB_PD_Charger_hw/release/USB_PD_Charger_fabrication.zip` — Gerber и сверление для изготовления платы.
- `USB_PD_Charger_hw/release/assembly` — справочная BOM и координаты монтажа.
- `USB_PD_Charger_fw` — исходники прошивки.
- `documents` — даташиты.

Финальные DRC, ERC и сверка схемы с платой: 0 ошибок и 0 предупреждений; неподключений 0. Разброс 38 линий SDRAM — 0,727 мм.

Перед заказом выбрать финишное покрытие и согласовать стек 4 слоя / 1,5 мм. F1–F5: выбран Bel 0680H9150-05, 15 А / 125 В DC. Обязательные требования к пяти вводам, БП и испытаниям — в USB_PD_Charger_hw/release/FUSE_SELECTION.md. Нагрузочные испытания устройства на 1 кВт не проводились; геометрическая проверка их не заменяет.

При изменении платы повторить проверки и обновить release. Промежуточные платы, логи трассировки и старые резервные копии вынесены из рабочей директории.
