# Used standard KiCad footprints

These 11 footprint files are unmodified copies of the installed KiCad 9.0.6 libraries, vendored so this project does not depend on a user's global footprint table. Their library nicknames are registered in the project `fp-lib-table`.

Source: https://gitlab.com/kicad/libraries/kicad-footprints

See `LICENSE.md` for the KiCad Libraries License. The board's active 3D model references point to the project-local `libs/3D` directory.
