# Рабочие библиотеки символов проекта

Это необходимые исходные файлы, а не временный кеш. Они содержат определения используемых символов из трёх файлов схемы и подключены через проектную `sym-lib-table`.

Графика и выводы сохранены. Для SDRAM нормализован идентификатор локальной копии; электрические сети не изменялись. Флагами PWR_FLAG обозначены существующие источники +24v, +3v3 и GND.

Стандартные символы KiCad сохраняют условия KiCad Libraries License в `KICAD-LIBRARIES-LICENSE.md`. Пользовательские определения сохраняют происхождение и условия исходных библиотек.
